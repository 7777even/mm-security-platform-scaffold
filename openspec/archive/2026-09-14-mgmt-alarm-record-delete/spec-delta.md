# Spec Delta

## 变更性质

纯前端 UI 扩展，**无对外接口 / 契约 / schema 变更**：
`DELETE /api/v1/alarms/{id}` 与前端 `deleteEmergencyEvent` 均已于既有交付中存在，本次仅新增调用入口。

## 受影响能力

- mgmt 后台管理端 · 报警管理域 · 报警记录页：新增删除写操作（`ADMIN` 角色门禁 + 审计留痕）。

## 验收

- 列表新增「操作」列；`ADMIN` 可见「删除」，非 `ADMIN` 显示「—」。
- 点击删除 → 二次确认 → 调用 `DELETE` → 审计上报 → 列表刷新。
- 删除失败有错误提示且不破坏列表。

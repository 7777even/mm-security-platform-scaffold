# 预案流程三级呈现方案（V1.0 待确认稿）

## 1. 目标

解决两个问题：

1. 预案流程信息过重，页面被矩阵占满，Cesium 地图完全不可见；
2. 交互层级单一，无法按“看流程 → 看细节 → 全屏操作”逐级深入。

方案把“预案全景全流程”拆成三级呈现：**流程条（L1）→ 页面内展开（L2）→ 全屏弹窗（L3）**，级别可随时切换，地图在 L1 时完整可见。

---

## 2. 三级定义

### L1 流程条（默认收起态）

- **形态**：页面中央顶部一条横向“135 应急处置流程条”，高度约 96px，仅保留流程核心信息。
- **内容**：
  - 左侧：事件徽标（事件处置/应急演练）+ 预案名（可省略标题只留徽标与预案名）；
  - 中部：9 个节点（编号/完成勾/进行中脉冲，节点名 + ?指导按钮）；
  - 右侧：阶段页签 + 时间轴（可横向滚动）、下一步、自动演示、`▸ 展开`、`▢ 详情`。
- **地图**：流程条下方即 Cesium 地图，地图完整可见、可拖拽缩放。
- **交互**：节点仍可点击（地图飞行 + 节点高亮）；?仍可打开处置指导；级别切换仍可用；矩阵不渲染。

### L2 页面内展开（当前阶段详情与指挥内容）

- **形态**：流程条展开为“当前所处阶段的详情和指挥内容”，占据页面中央区域。
- **内容**：
  - 左侧：当前节点指挥卡（节点名称/指挥层级/负责角色/描述/标准响应操作/完成标准/升级规则）；
  - 右侧：当前阶段指挥与动作（实时值班表 + 当前阶段动作清单，按参战力量分组，可点击查看详情/切换状态）。
- **地图**：被模块覆盖，可通过“⤴ 收起”回到 L1 查看地图。
- **交互**：阶段切换（班组处置→运行部级→公司级→政府级，升级带确认）、节点点击/指导、下一步/自动演示、动作卡详情与三态切换。
- **不包含**：全量预案矩阵、节点配置（⚙）、切换预案、全景/聚焦、新增/删除卡片、列宽拖拽、右键管理菜单——这些管理能力统一放到 L3 详情。
- **与 L3 的差异**：L2 聚焦“当前阶段怎么处置、谁来指挥”；L3 提供全量矩阵与编辑管理。

### L3 全屏弹窗（详情视图）

- **形态**：Teleport 全屏弹窗，在 L2 基础上增加：全景/聚焦模式、切换预案、预案选择、节点配置（⚙）、新增/删除动作卡、列宽拖拽、卡片右键管理菜单。
- **入口**：L1/L2 的 `▢ 详情` 按钮，以及左侧“预案面板 → 预案矩阵”。
- **返回**：关闭弹窗后回到打开前的层级（L1 或 L2），不丢失状态。

---

## 3. 级别切换规则

| 操作                   | 当前 L1             | 当前 L2             | 当前 L3        |
| ---------------------- | ------------------- | ------------------- | -------------- |
| `▸ 展开`               | → L2                | -                   | -              |
| `⤴ 收起`               | -                   | → L1                | -              |
| `▢ 详情`               | → L3（记忆返回 L1） | → L3（记忆返回 L2） | -              |
| 关闭弹窗               | -                   | -                   | → 返回记忆层级 |
| 节点点击/指导/级别切换 | 可用                | 可用                | 可用           |

- 层级状态用 `sessionStorage` 持久化（刷新后保持用户选择）。
- L3 打开期间，页面其他 UI 不响应（遮罩），关闭后恢复。

---

## 4. 地图可见性规则

| 场景              | 地图可见性                       |
| ----------------- | -------------------------------- |
| L1 流程条         | ✅ 完整可见（模块仅占顶部 96px） |
| L2 页面内展开     | ❌ 被模块覆盖；可收起            |
| L3 全屏弹窗       | ❌ 被遮罩覆盖；关闭即恢复        |
| 左侧栏/右侧栏收起 | ✅ 左右各释放 419px 地图空间     |

配套增加左右侧栏“展开/收起”按钮（页面边缘悬浮），默认展开，收起后地图横向视野扩大。

---

## 5. 交互与视觉要求

- 三个级别共用同一套 safety-master 设计语言（深色 slate、蓝/红主题、节点脉冲）。
- 切换动效：L1↔L2 使用高度/透明度过渡（280ms，`cubic-bezier(0.22,1,0.36,1)`）；L3 使用现有弹窗过渡。
- 所有按钮 hover/active 有反馈；收起/展开按钮有明确图标与 tooltip。
- 1366 / 1920 / 2560 三档尺寸下：L1 流程条不换行，顶部阶段+时间轴排不下可左右滑动，L2 详情内容不遮挡左右/底部元素。

## 7. 流程阶段划分与视觉方案

依据客户文档《茂名石化突发事件总体应急预案》：

- “135”原则：1 分钟内应急响应（能量隔离、切断物料等关键操作）；3 分钟内退守稳态；5 分钟内消气防联动。
- 响应分级：运行部级（装置区）/ 公司级（全厂）/ 政府级（地方政府）。
- 收尾：应急终止 → 总结评估与恢复。

9 节点划分为 5 个阶段（顶部阶段页签 + 时间轴分段色带）：

| 阶段         | 节点 | 色带 | 含义                                                       |
| ------------ | ---- | ---- | ---------------------------------------------------------- |
| 班组处置     | 1-4  | 蓝   | 接警研判、一分钟应急响应、三分钟退守稳态、五分钟消气防联动 |
| 运行部级应急 | 5    | 青   | 装置区专项预案                                             |
| 公司级应急   | 6    | 金   | 全厂预案                                                   |
| 政府级应急   | 7    | 红   | 政企联动                                                   |
| 收尾阶段     | 8-9  | 绿   | 应急终止、总结评估与恢复                                   |

视觉：顶部为 5 个阶段页签（可点击，升级需确认）+ 时间轴；时间轴背景按阶段着色分段，节点按序排布、进行中脉冲高亮；顶部整块支持横向滚动，后续节点增加可继续左右滑动。

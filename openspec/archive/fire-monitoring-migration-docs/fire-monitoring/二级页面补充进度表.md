## 执行规则（已固化）

1. 视觉与交互**严格对齐 mm-UIproject（fire-monitoring）现有实现与设计规范**，不以原型 PDF 的孤立样式为准；
2. 新增页面/组件前，先排查是否与原项目**重复、冲突**；
3. 逻辑存疑、与原项目冲突/重复、或存在其他疑问的条目，**必须先经用户确认再实现**；
4. 每完成一批改动，更新本表并把状态同步给用户确认；
5. 实验性/未定稿功能（如“设备3D详情+脑机”）不实现。

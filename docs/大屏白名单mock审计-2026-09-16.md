## 结论速览

- **18 个白名单模块全部为 by-design**（UI 结构 / 几何坐标 / DEV 回落解析器 / demo 离线兜底）。
  所有「被引用的真实业务数据」导出（消防力量、抓拍、应急事件、值班、流程、防汛力量…）
  **当前均已双态**：live 走 `@/services`，demo/offline 才回落本地副本——本地 copy 属 by-design 兜底，
  **无需转换、不应删除**。
- 可安全清理的只有**悬空/死代码**：删 `nav`（文件早已不存在）、删 `preliminaryMock` 两个死 value 导出、
  删 `mock` 三个死 value 导出。均已本次执行，门禁仍 PASS。
- 未做大批量删除：各模块内部仍有零散死导出（non-whitelisted，门禁不拦），但批量删风险高、收益低，
  留待后续按需清理（见末节清单）。

## 2. 已落地的性能与安全相关基础设施（本次详设 V1.5 对齐新增）

1. **防重放签名不影响首屏链路**：签名（`src/services/requestSigner.ts`，HMAC-SHA256 Web Crypto）仅在携带令牌的 API 请求启用，静态资源与 Mock（dev bypass）不涉及；单次 `subtle.sign` 耗时亚毫秒级，不构成 SLA 风险。
2. **Strict-XSS 深度转义**：`src/utils/sanitize.ts` 仅处理出站 JSON 请求体，递归遍历为微秒级开销；大表单（>1000 字段）场景 G1 实测时抽查。
3. **Accept-Language 头**：纯 Header 设置，零耗时影响。

## 3. G1 真机实测待办（回填本文件）

5. 审批变更响应：BPMN 特性落地后按本地重渲染口径补测（≤150ms）。

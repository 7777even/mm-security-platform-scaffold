# 设计文档：指挥大屏视觉升级（2026-08-18）

> 前置：`docs/superpowers/specs/2026-08-18-scaffold-rebuild-design.md` 的脚手架基座已就绪；本次为样式层的精致化升级，逻辑/门禁/红线不动。

## 背景与目标

脚手架当前视觉呈"占位页"形态（平铺玻璃面板 + 侧边栏后台布局）。用户要求按**指挥大屏/专业系统**的视觉标准精致化，并给出石化智云 UI 规范要点：Logo 左上角、间距（外边距 16px / 内边距 24px）、字号（标题 16px / 正文 14px）、列表隔行变色、微软雅黑、大屏深色科技蓝、少即是多高对比。

## 设计原则

1. **spec 红线不变**：设计 token 基准 `#0F1E36` 安全工业蓝保留，作为基底色。
2. **大屏语感**：参照 mm-safety-master 的深底 + 青色发光面板语言，但收敛噪点。
3. **少即是多**：文本高对比、高易读，避免不必要的视觉噪点。
4. **兼容下限**：Chromium 86（backdrop-filter 已支持；不使用过新 CSS 特性）。

## 视觉系统

### 设计 Token（tokens.css 重构）

| Token | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#050A15` | 页面基底深色 |
| `--color-primary` | `#0F1E36` | spec 红线工业蓝 |
| `--color-primary-soft` | `#16304F` | 面板底色 |
| `--color-accent` | `#00D4FF` | 青蓝发光强调 |
| `--color-accent-glow` | `rgba(0,212,255,0.35)` | 发光光晕 |
| 字体 | 微软雅黑优先 | 全局正文 14px / 标题 16px |
| 间距 | 页面外边距 16px / 面板内边距 24px | 石化智云规范 |
| `--row-alt-bg` | 隔行变色底 | 列表斑马纹 |

### 全局样式（global.css）

- 深蓝渐变背景 `linear-gradient(#050A15, #0F1E36)` + 微弱科技网格/光晕（克制）。
- 细窄青色滚动条。
- `.glass-panel` 升级：半透明深蓝底 + 青色渐变描边 + 顶部亮线 + 内发光 + hover 微光。

### 布局（AppLayout.vue 重构）

```
┌──────────────────────────────────────────────────────┐
│ [盾牌Logo] 安全管控指挥系统 │ 模块导航(按meta.perm) │ 时钟|角色 │
├──────────────────────────────────────────────────────┤
│                    <router-view/> 全屏内容区          │
│             页面面板横铺，导航高亮当前模块              │
└──────────────────────────────────────────────────────┘
```

- 左：风格化盾牌 SVG（占位，正式接入替换中石化品牌资产）+ 发光标题；**点击 Logo 返回 `/`**。
- 中：模块导航（综合态势/火灾报警/工业视频/用户与权限），复用 `usePermission().filterRoutesByPerm` 过滤。
- 右：秒级实时时钟 + 角色切换（复用 `useAuthStore`）。

### Dashboard

- 顶部 4 张指标卡：发光大数字 + 语义色图标（token 驱动）。
- 中部：告警/处置趋势 ECharts，青色发光折线 + 深色网格 + 发光 tooltip。
- 底部：实时告警列表（隔行变色 + 状态色点）。

### 其余页面统一

- fire-alarm / industrial-video / system-users / NotFound：统一精致面板形态（发光标题栏 + 内容区），保留占位文案，消除占位感。

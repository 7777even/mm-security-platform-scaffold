# UI 规范 — 移动端

> **本文档定位**：AI 助手 / 开发者在生成或评审**移动端（APP / H5）**页面代码时的**权威执行规范**（CLAUDE.md 风格，规则必须逐条遵守）。
> **数值真源**：`src/styles/tokens.css` 中 `[data-theme='mobile']` 块（本文只引用 token 名，不复制 hex 进代码）。
> **设计依据**：《安全管控平台设计说明 V1.2》§5.3.1.3 / §5.3.2 / §5.3.3.3 / §5.3.3.3.1 / §5.3.5.3 / 第 7 章；《详细设计 V1.5》§3.3 / §3.4（户外强光皮肤、触控热区 48–56）。
> **后台管理端规范**：见 `docs/UI规范-后台管理端.md`；大屏端规范见 `docs/UI规范-大屏端.md`。

---

## 0. 快速接入（每次生代码前先做）

1. 在应用根节点挂载主题：`data-theme="mobile"`。
2. 引入 `src/styles/tokens.css`，**禁止**在组件或页面里重定义任何 `--token`。
3. 所有颜色 / 字号 / 间距 / 圆角 / 尺寸一律 `var(--token)` 引用，**禁止硬编码**。
4. 需要状态 / 报警等级着色 → 只用 §8 映射表与 `.tag-*` 类，**禁止自造色阶**。
5. 新增页面先查 §5.1 页面形态索引，找同形态既有页面作参照。
6. 完成后按 §9 自检清单逐条核对；任一「禁止」命中必须重写。

## 1. 通用硬性规则

1. **MUST** 移动端为**浅色服务型视觉**：浅灰底 + 白色卡片 + 主色蓝行动点。强调单手可达、信息分块清晰与操作路径短，设计遵循「轻量化、场景化、高可用」。
2. **MUST NOT** 把大屏深色态势风格迁移到小屏：禁止深蓝黑底、科技青 `#00d8ff`、玻璃质感（`--glass-*`）、发光边框、发光抽屉。这些**仅限大屏端**。
3. **MUST** 面向厂区户外 / 强光屏使用，**对比优先于装饰**：关键信息（标题、列表主文、主按钮、表单必填）必须在高亮度下仍可扫读；减少对浅描边与浅灰字的依赖。
4. **MUST** 触控优先：可点击区域物理高度**严格控制在 48px 至 56px 之间**（详设 V1.5 §3.4），列表行、主按钮、底栏标签均按拇指操作设计，**避免过密热区**。
5. **MUST** 优先展示报警、待办、任务等动态信息；高频入口集中在首页分区与底栏，流程页用步骤条提示进度，减少用户迷失。
6. **MUST** 状态表达统一用「浅底 + 同色深字 + 同色边框」标签（`.tag-success / -warning / -danger / -info`）；未读提示用小红点角标，不改图标本体色相。
7. **MUST** 同屏字号档位 **≤ 4 级**，逐级递减：首页主标题 > 页标题 > 区块标题 > 表单标签 / 辅助说明。
8. **MUST** 反馈按打断程度分级使用：轻提示 < 居中确认 / 底部选择器 < 结果页，保证操作闭环可见。**一屏仅一个主按钮**。
9. **MUST** 适老模式 / 户外高对比**全局同步生效**（首页、列表、表单、弹层、底栏一起放大或加深），只放大字号 / 控件 / 间距，**不改变业务流程与字段结构**，可随时关闭回退。
10. **MUST NOT** 用过浅灰字作为唯一说明；禁止高亮浅字；主色仅用于选中态与关键行动。
11. **MUST** z-index 只用五层 token：`--z-base(0) / --z-marker(5) / --z-chrome(10) / --z-overlay(30) / --z-toast(40)`，禁止随手写 `z-index:999`。

## 2. 色彩 Token

| 用途                             | Token                                                   | 值                                                            |
| -------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------- |
| 页面灰底                         | `--bg-mobile`                                           | `#f4f7fa`                                                     |
| 内容白卡                         | `--card-mobile`                                         | `#ffffff`                                                     |
| 分割线                           | `--border-mobile`                                       | `#e6edf4`                                                     |
| 主色蓝（主按钮 / 选中态 / 链接） | `--primary-mobile`                                      | `#1677ff`（户外场景可略加深至 `#0A5FCC`）                     |
| 主色浅底（信息卡 / 即时标签底）  | `--primary-mobile-soft`                                 | `#e8f2ff`                                                     |
| 标题墨蓝                         | `--text-title-mobile`                                   | `#183b5b`                                                     |
| 正文灰蓝                         | `--color-text`                                          | `#1e3a52`（≥4.5:1）                                           |
| 次要灰蓝                         | `--text-muted-mobile`                                   | `#8aa0b3`                                                     |
| 成功 / 警示 / 危险               | `--success-mobile` `--warning-mobile` `--danger-mobile` | `#22c55e` / `#fa8c16` / `#f5222d`（深色字 + 浅底 + 同色描边） |

## 3. 布局骨架与导航（基准画板 375 宽）

- **内页顶栏** `--mb-header-h: 48px`：白底，左返回、中标题。
- **首页顶栏**：沉浸头图顶栏（**仅首页允许**），头图区 + 品牌提示条 + 快捷四宫格 + 业务大卡区 + 圆形图标网格，视觉权重自上而下递减，保证高频入口优先被发现。
- **底部标签栏** `--mb-bottom-bar-h: 56px`：固定 4 入口「首页 / 任务 / 消息 / 我的」，支持单手操作；选中 = 主色图标 + 文字，未选中 = 次要灰。
- **流程页**：不使用底栏，改用底部主操作条。
- **安全区**：顶栏 / 底栏 / 主操作条必须预留 `var(--mb-bottom-safe)`（`env(safe-area-inset-bottom)`），避免控件被刘海与系统手势遮挡。

### 3.1 字号（同屏 ≤ 4 档）

| 角色            | Token                | 值          |
| --------------- | -------------------- | ----------- |
| 首页主标题      | `--mb-fz-hero`       | `28px` 加粗 |
| 页标题          | `--mb-fz-page`       | `20px` 中粗 |
| 区块标题        | `--mb-fz-section`    | `17px` 中粗 |
| 表单标签 / 正文 | `--mb-fz-form-label` | `15px`      |
| 辅助说明        | `--mb-fz-help`       | `14px`      |
| 次要提示        | `--mb-fz-tip`        | `12px`      |

### 3.2 间距与圆角

页面左右边距 `--mb-pad-x: 16px`；卡片间距 `--mb-card-gap: 12px`（12–16）；列表行高 `--mb-row-h: 48px`（48–56）；卡片圆角 `--mb-radius-card: 16px`（柔）；按钮胶囊 `--mb-radius-btn: 999px`；控件 `--mb-radius-ctrl: 8px`。通过灰底「露白」区分卡片组，避免信息贴死。

## 4. 核心组件规则

**卡片与列表**

- 标准白卡：圆角统一、内边距充足；只读摘要可用浅主色信息卡 `--primary-mobile-soft` 区分。
- 列表行：左文右箭头，细分隔线分隔同行；关键分区优先用间距与卡片灰底区分，**弱依赖 1px 浅分割线**。
- 消息列表：独立浅底条目呈现标题、摘要、时间。

**表单与流程**

- 表单按组收入白卡，行结构「左标签（用标题色）右值 / 占位」；可选项带箭头进入底部选择器。
- **占位符不得替代必填说明**；必填标记明确。
- 多步流程顶部步骤条：当前步实心主色、已完成描边主色、未到灰。

**按钮与主操作**

- 主按钮：**实心主色胶囊 + 白字**，高 `--mb-btn-h: 48px`，承担提交 / 下一步等唯一主行动；**不得以浅色描边按钮作为唯一主操作**。
- 次按钮：白底 + 深描边（描边 ≥`#7FA3C4`）+ 深色字，保证眩光下外轮廓可见；文字链接用于弱操作。
- 底部主操作条贴边固定 + 预留安全区；**一屏仅一个主按钮**。

**弹层与反馈**

- 居中弹窗：须知与确认；底部弹层：选择器与轻量编辑。
- 反馈分级：轻提示 < 确认弹窗 < 结果页。
- 空状态：插画位 + 说明文案 + 引导按钮。
- `z-index: var(--z-overlay)`；**禁止**使用玻璃质感弹层。

**状态标签与图标**

- 状态用 `.tag-*` 浅底同色深字标签，**必须加同色边框**（户外可见）。
- 服务图标：圆角方底 / 圆形浅底承载线面结合图标，同网格视觉重量一致；图标线宽 ≥1.6，选中态用实色底或深描边。

**推送与消息交互**

- 推送通知点击**直达关联详情页**（报警推送 → 报警详情，事件通知 → 事件详情）；支持通知历史列表查看。
- 消息中心按类型分类展示，支持类型筛选与**批量标记已读**。
- 指令 / 任务类消息支持一键确认接收、填写处置反馈、标记完成；**超时未响应自动提醒**。

**场景交互细则**

- 巡检 / 作业票执行：逐项勾选 + 拍照上传 + 文字备注；发现异常填写描述并**自动生成异常工单**。
- 应急辅助资料：分类浏览 / 关键词搜索，PDF / 图片在线预览，常用资料**离线缓存**。
- 值班信息：排班日历 + 当日值班人员列表，**一键拨打**值班人员电话。
- 视频：实时画面 + PTZ 云台控制 / 变焦 + 截图保存到本地。
- 路径导航：事件 / 点位一键发起导航；危化品 MSDS 按名称 / 类别快速检索。
- 全局手势：下拉刷新、上拉加载、列表左滑快捷操作；离线操作缓存（复用 `src/composables/useOfflineOutbox.ts`）。

**权限**

- 首页报警统计概览、列表与详情按**当前用户权限范围**展示；数据权限由服务端过滤，前端只做显隐。
- 权限点控制按钮显隐（复用 `src/directives/permission.ts` 的 `v-permission` 指令）。

## 6. 户外强光模式（详设 V1.5 §3.4「高反差单色皮肤」）

户外强光 / 高亮屏场景切换到**锁死的高反差皮肤**（根节点叠加 `data-skin="outdoor"`，token 块见 tokens.css 末尾），而非常规态微调：

- **纯白 `#FFFFFF` 底 + 纯黑 `#000000` 文字**，对比度 WCAG AAA（>7:1）；层级靠字号与字重拉开，不靠颜色。
- **全面停用渐变、软投影、毛玻璃、浅灰装饰线**；分割线转纯黑硬线。
- 状态标签**取消浅底同色样式**，改为**高饱和纯色色块填充 + 白字 + 深色硬描边（2px solid 黑）**。
- 常规态下（未开皮肤）仍需满足基础对比：标题 ≥18 / 正文 ≥15、无过浅灰字作唯一说明。

## 7. 适老模式

- 入口：「我的 → 适老与无障碍」：一键适老 + 细项调节（字号 标准/大/特大、按钮与列表放大、高对比显示），设置即时预览，可随时关闭回退；与户外高对比可叠加生效。
- 开启后全局同步：行高 ≥56（`--mb-row-h-elder`）、主按钮 ≥48（`--mb-btn-h-elder`）、列表标题 / 主按钮 / 状态标签同步放大。
- 字号档位（正文-标题-辅文）：标准 15/18/13，大 17/20/15，特大 19/22/17；**大字模式行高弹升至 1.8 倍字号，核心字段不作截断、自适应换行**（详设 V1.5 §3.4）。
- 不改变业务流程与字段结构。

## 8. 状态与等级映射（枚举，复制即用）

```ts
// 报警等级（移动端渲染为浅底标签）
export type AlarmLevel = 1 | 2 | 3 | 4;
export const ALARM_LEVEL_COLOR: Record<AlarmLevel, string> = {
  1: 'var(--color-alarm-1)',
  2: 'var(--color-alarm-2)',
  3: 'var(--color-alarm-3)',
  4: 'var(--color-alarm-4)',
};

// 报警状态 → 标签
export const ALARM_STATUS_META = {
  ACTIVE: { label: '待处理', tagClass: 'tag-danger' },
  ACKED: { label: '已确认', tagClass: 'tag-warning' },
  DISPATCHED: { label: '已派单', tagClass: 'tag-info' },
  CLOSED: { label: '已闭环', tagClass: 'tag-success' },
} as const;

// 设备状态
export const DEVICE_STATUS_COLOR = {
  ONLINE: 'var(--color-success)',
  OFFLINE: 'var(--color-text-muted)',
  FAULT: 'var(--color-danger)',
} as const;
```

报警等级 → 标签色：一级 `#f5222d` 红、二 / 三级 `#fa8c16` 橙、四级主色蓝（token：`--color-alarm-1..4`）。

## 9. 代码生成自检清单

- [ ] 根节点挂了 `data-theme="mobile"`，未重定义 token，无硬编码色 / 字号 / 尺寸。
- [ ] 同屏字号 ≤ 4 档；状态全部用 `.tag-*` 或 §8 映射，无自造色。
- [ ] 无大屏风格泄漏（玻璃 / 发光 / 科技青 / 深色底）；无左右双栏与地图壳层。
- [ ] 基准 375；单列卡片布局，边距 16、卡片间距 12–16、行高 48–56。
- [ ] 底栏 4 入口（流程页换底部主操作条）；安全区 `env(safe-area-inset-bottom)` 已预留。
- [ ] 触控热区严格 48–56px，无过密热区；主按钮高 ≥48。
- [ ] 主按钮实色胶囊白字且一屏一个；次按钮白底深描边；状态标签带同色边框。
- [ ] 户外基础对比达标（标题 ≥18 / 正文 ≥15）；强光皮肤 `data-skin="outdoor"` 下纯黑白高反差、无渐变/投影/毛玻璃、标签为高饱和色块+硬描边。
- [ ] 推送点击直达详情；消息中心支持分类筛选与批量已读。
- [ ] 数据按当前用户权限范围展示；按钮按权限点控制显隐。
- [ ] 反馈分级正确；空状态有插画 + 文案 + 引导按钮。
- [ ] z-index 只用五层 token。
- [ ] 适老档位可全局切换（行高 ≥56、主按钮 ≥48）且可随时回退。

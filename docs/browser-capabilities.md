# 浏览器能力下限（信创部署）

> 本文档定义前端须兼容的**信创浏览器能力下限**与降级策略。前端特性选型、polyfill 引入与功能降级开关须以此为准。
> 基线锚定 **Chromium 86**（石化窗等设备当前兼容下限；详见 §1）。

## 1. 部署与目标浏览器

| 部署     | 浏览器构建          | 内核                               | 备注            |
| -------- | ------------------- | ---------------------------------- | --------------- |
| 石化窗   | 石化窗内置浏览器    | Chromium 86                        | 兼容下限        |
| 海光 C86 | 银河麒麟内置浏览器  | Chromium（**待运维确认**具体版本） | 海光平台        |
| 麒麟 V10 | 麒麟 V10 内置浏览器 | Chromium（**待运维确认**具体版本） | 飞腾 / 鲲鹏平台 |

> 能力差异主要来自**浏览器内核版本**而非 CPU / OS；上表「待运维确认」项需运维提供实际构建版本后补全。

## 2. 能力清单对照表

| 能力         | 说明                      | 石化窗 Chromium 86                 | 海光 C86       | 麒麟 V10       | 检测方式                                   |
| ------------ | ------------------------- | ---------------------------------- | -------------- | -------------- | ------------------------------------------ |
| WebGL        | 2D/3D 地图与图表          | ✅（ANGLE / SwiftShader 软渲兜底） | ⚠️ 待确认      | ⚠️ 待确认      | `'WebGLRenderingContext' in window`        |
| Web Audio    | 音频合成 / 提示音         | ✅                                 | ⚠️ 待确认      | ⚠️ 待确认      | `typeof AudioContext !== 'undefined'`      |
| WASM         | 高性能计算（国密 / 解析） | ✅                                 | ⚠️ 待确认      | ⚠️ 待确认      | `typeof WebAssembly !== 'undefined'`       |
| 国密 SM2/3/4 | WebCrypto 原生不支持      | ❌ 需 polyfill                     | ❌ 需 polyfill | ❌ 需 polyfill | `crypto.subtle` 无 SM 摘要算法             |
| MSE          | 视频流式播放              | ✅                                 | ⚠️ 待确认      | ⚠️ 待确认      | `'MediaSource' in window`                  |
| WebRTC       | 实时音视频（视频融合）    | ✅                                 | ⚠️ 待确认      | ⚠️ 待确认      | `typeof RTCPeerConnection !== 'undefined'` |

> Chromium 86 原生支持 WebGL / Web Audio / WASM / MSE / WebRTC；**国密（SM2/3/4）WebCrypto 原生不支持**，必须 WASM polyfill。

## 3. 降级策略

- **国密**：经 WASM polyfill（如 `sm-crypto`）在前端实现 SM2/3/4；非国密环境回退至 WebCrypto 标准算法（SHA-256 / AES）。引入 `sm-crypto` 须评估包体积与初始化耗时。
- **WebGL 不可用**：地图底座回退至静态底图 / 矢量瓦片；3D 场景提示「当前环境不支持 WebGL」。
- **Web Audio 不可用**：静默降级，关键提示改用视觉（toast / 高亮）触达。
- **MSE / WebRTC 不可用**：视频回放降级为渐进式下载（HLS / MP4）；实时视频提示「环境不支持」。
- **功能降级开关**：以 feature flag 控制能力敏感特性；检测失败即关闭对应功能并给出用户可理解提示，避免白屏 / 崩溃。

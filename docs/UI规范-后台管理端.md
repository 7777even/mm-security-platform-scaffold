# UI 规范 — 后台管理端

> 端间边界红线（后台禁止玻璃质感 / 科技青 / 发光，且不得使用门户学习卡片）见 `docs/UI规范-门户与后台边界.md`。

> **本文档定位**：AI 助手 / 开发者在生成或评审**后台管理端（PC 管理后台）**页面代码时的**权威执行规范**（CLAUDE.md 风格，规则必须逐条遵守）。
> **数值真源**：`src/styles/tokens.css` 中 `[data-theme='mgmt']` 块（本文只引用 token 名，不复制 hex 进代码）。
> **设计依据**：《安全管控平台设计说明 V1.2》§5.3.1.2 / §5.3.2 / §5.3.3.2 / §5.3.3.2.1 / §5.3.5.2 / 第 7 章；《详细设计 V1.5》§3.4（石化智云 UI 基线：表格隔行变色、Logo 点击回主页）。
> **大屏端规范**：见 `docs/UI规范-大屏端.md`；移动端规范见 `docs/UI规范-移动端.md`。

## 0. 快速接入（每次生代码前先做）

1. 在应用根节点挂载主题：`data-theme="mgmt"`。
2. 引入 `src/styles/tokens.css`，**禁止**在组件或页面里重定义任何 `--token`。
3. 所有颜色 / 字号 / 间距 / 圆角 / 尺寸一律 `var(--token)` 引用，**禁止硬编码**。
4. 需要状态 / 报警等级着色 → 只用 §7 映射表与 `.tag-*` 类，**禁止自造色阶**。
5. 新增页面先查 §5.1 页面形态索引，找同形态既有页面作参照。
6. 完成后按 §8 自检清单逐条核对；任一「禁止」命中必须重写。

## 1. 通用硬性规则

1. **MUST** 后台为**浅色办公管理视觉**：浅灰底 + 白色内容卡 + 主色蓝行动点。深蓝顶栏建立品牌带，浅底白卡建立阅读场。强调表格可读、筛选可达与流程可追踪。
2. **MUST NOT** 把大屏深色态势风格迁移过来：禁止深蓝黑底、科技青 `#00d8ff`、玻璃质感（`--glass-*`）、发光边框、发光抽屉、渐变大按钮。这些**仅限大屏端**。
3. **MUST** 状态表达统一用「浅底 + 同色深字」标签（`.tag-success / -warning / -danger / -info`）；侧栏与列表合计用浅蓝胶囊提示数量，不抢正文视线。
4. **MUST** 同屏取用字号 **≤ 4 档**，逐级递减：标题 > 区块标题 > 正文 > 辅助说明（§3.1 token 共 6 档按场景取用；设计说明 §5.3.3.2 对适老模式明确要求同屏仍控制在四级以内）。
5. **MUST** 反馈按打断程度分级使用：页内提示条 < 轻提示（Toast）< 确认弹窗 < 大编辑弹窗。**一屏主行动唯一**。
6. **MUST** 适老模式**全局同步生效**（侧栏、表格行高、筛选控件、主按钮一起放大），只放大字号 / 控件 / 间距，**不改变业务流程与字段结构**；字号与密度偏好按账号记忆。
7. **MUST NOT** 用过浅灰色作为唯一说明文字；关键信息必须保证对比度（标题墨蓝、正文灰蓝、次要浅灰）。
8. **MUST** z-index 只用五层 token：`--z-base(0) / --z-marker(5) / --z-chrome(10) / --z-overlay(30) / --z-toast(40)`，禁止随手写 `z-index:999`。
9. **MUST** 登录页可用蓝渐变品牌卡营造信任感；进入工作台后切回浅色办公场，**禁止**把登录渐变延伸进表格页。

## 3. 布局骨架（T 型）

- **顶栏** `--mgmt-header-h: 56px`：深蓝渐变品牌带，**Logo 置左上角且点击返回主页**（详设 V1.5 §3.4），承载品牌、全局搜索、消息通知、用户中心、快捷操作、适老模式开关。快捷图标用白描线落在半透明圆角底上。
- **侧栏** `--mgmt-aside-w: 220px`（折叠 `64px`）：一级 / 二级导航，按「系统管理 — 业务专题 — 数据统计」三级组织，支持折叠展开。菜单项高 `--mgmt-sidebar-item-h: 40px`（工程适配值，基准仅约束适老档 ≥48）；选中态仅改主色 + 浅蓝底，**不改线宽、不加发光**。
- **主内容区** `--mgmt-content-pad: 24px`（可 24–32）：以业务模块为单元，「卡片 + 表格 + 表单」模块化组织，纵向排布「页标题 → 筛选卡 → 列表 / 表单」，白卡承载，卡片间距充足，表格细分隔线避免信息贴死。
- **向导页**：可去掉侧栏，保留顶栏 + 居中内容卡。

## 4. 核心组件规则

**筛选卡**（列表页顶部白卡内）

- 下拉 / 文本 / 日期控件**等高** `--mgmt-ctrl-h: 40px`；右侧「主查询（实色主色）+ 次重置（白底描边）」成组。

**数据表格**

- 表头：浅主色底 `--primary-mgmt-soft` + 墨蓝字 `--text-title-mgmt`；行：白底 `--card-mgmt` + 细分隔线 `--border-mgmt`；行高 `--mgmt-table-row-h: 48px`；**开启隔行变色（斑马纹）**（详设 V1.5 §3.4，隔行底用页面灰底 `--bg-mgmt`）。
- 状态列：`.tag-*` 浅底同色标签；**禁止**纯色字、灰蓝底、发光。
- 操作列：主操作 = 浅底小按钮（`.tag-info` 风格），弱操作 = 文字链接；内嵌小表中「编辑」主色链接、「删除」危险红链接。
- 分页：当前页实心主色圆，页码跳转输入贴右。

**表单与流程**

- 多步向导顶部放**水平步骤条**：当前步实心主色、已到描边主色、未到灰，连线同态。
- 表单区用**左色条 + 分区标题**组织；双列栅格排布输入；须知用浅橙提示条 `--warning-mgmt-soft`。
- 详情审核轨迹用**垂直时间轴**：序号圆节点 + 竖线串联，卡片浅底与节点色一致（成功绿 / 信息蓝 / 驳回红 / 未到灰），时间戳右置，顶部可附总状态标签。
- 同级内容切换用**页签下划线**；步骤条、时间轴、页签三者分工明确，**禁止混用**。

**按钮**

- 主按钮：实色 `--primary-mgmt` 白字，高 `--mgmt-btn-h: 32px`；次按钮：白底描边；表内主操作：浅底按钮；顶栏次操作：白底胶囊。
- **一屏主行动唯一**。

**弹层**

- 大弹窗：白底圆角（`--mgmt-radius-lg: 10px`），顶栏标题 + 关闭，底栏「取消 / 确定」；遮罩深色半透明 `rgba(0,0,0,.45)`；可叠二级确认弹窗，关闭顺序自上而下。
- `z-index: var(--z-overlay)`；**禁止**照搬大屏抽屉发光边框。

**图标**

- 侧栏约 20px 线框图标，选中仅改主色、不改线宽；顶栏快捷为白描线图标；表单区控件图标与主色体系统一；同列视觉重量一致。

**间距/字号基线说明（石化智云 UI 规范，详设 V1.5 §3.4）**：《石化智云 UI 规范》推荐外边距 16 / 内边距 24、标题 16 / 正文 14，并注明可按分辨率及视距动态适配；本端细化值（页边距 24、页标题 28、区块标题 22、侧栏项 40、主按钮高 32）属该授权范围内的适配值，验收时以本端规范为准。注意：基准适老档位（正文 16–18、页标题 22–24）基于基准 16px 标题基线，本端适老开启后各档位须**不低于标准档**并同步放大，保持适老放大逻辑（见 §6）。

**字体**：中文默认字体推荐「微软雅黑」（Microsoft YaHei，详设 V1.5 §3.4），与中石化品牌规范一致；页标题、区块标题、表头、单元格、辅助说明按 §3.1 逐级递减。表格隔行变色（斑马纹，§4 数据表格已强制）亦对齐《石化智云 UI 规范》品牌要求。

**圆角**：控件按基准约 `6–8px`（设计说明 §5.3.3.2；tokens.css 现值 `--mgmt-radius-sm/md: 4/6px` 待同步至 6/8）；卡片 `--mgmt-radius-lg: 10px`（基准 10–12）。

**典型管理交互**（以下为管理端页面标配能力）

- 列表页标配：多条件检索、筛选重置、数据导出、批量操作（勾选 + 批量删除 / 批量导出）。
- 行内（内联）编辑仅用于简单字段；复杂编辑一律走弹窗或编辑页。
- 一个业务对象多视角用**子页签**组织（如备案车辆：列表 / 白名单 / 黑名单；道闸：人闸 / 车闸）。
- 台账类详情用「基础信息 + 关联子表」呈现（如应急队伍详情内嵌车辆 / 物资表格）。
- 需要地理定位的台账（消防重点部位、防撞柱、监控池等）支持**地图坐标标注**。
- 一键状态控制（如道闸开 / 关 / 常开三种状态）点击即时切换，并给出明确状态反馈。
- 附件 / 照片上传与在线预览为台账类页面标配；表单提交校验必填项与字段格式。

**主动触达**

- 报警、预警、应急指令等动态信息通过高亮动效、颜色变化、弹窗提示主动触达用户。
- 关键操作入口始终可见，支持一键定位、一键调阅、一键处置。

**权限与留痕**

- 功能权限与数据权限按「岗位 + 角色」定义；菜单与按钮按权限点控制显隐（复用 `src/directives/permission.ts` 的 `v-permission` 指令）。
- 权限变更留痕；关键操作写入审计日志。
- 组织架构与人员账号对接企业统一身份系统，后台**不提供**账号增删改，仅同步岗位角色映射。

## 5. 页面模板

| 页面形态      | 骨架                                                            |
| ------------- | --------------------------------------------------------------- |
| 列表页        | 顶栏 + 侧栏 + （页标题 → 筛选卡 → 数据表格 → 分页）             |
| 详情页        | 顶栏 + 侧栏 + （页标题 → 总状态标签 → 信息卡分组 / 垂直时间轴） |
| 编辑 / 新增页 | 列表页内大弹窗，或独立页左色条分区表单                          |
| 向导页        | 顶栏 + 居中内容卡（步骤条 → 表单 → 底部「上一步 / 下一步」）    |
| 多 Tab 业务页 | 页内页签下划线切换，每页签内仍走「筛选 → 表格」模板             |
| 主从布局页    | 左列表右详情，选中态浅主色底                                    |
| 登录页        | 蓝渐变品牌卡居中，独立于工作台浅色场                            |

交互遵循 **列表页 → 详情页 → 编辑页** 三级跳转逻辑，路径清晰可控，满足台账维护、数据审核、流程审批等办公需求。

## 6. 适老模式

- 入口：顶栏一键开关 + 个人设置细项（字号档位、界面密度）。
- 开启后同步放大：侧栏菜单项 ≥48（`--mgmt-sidebar-item-h` 适老档）、筛选控件 ≥48（`--mgmt-ctrl-h-elder`）、主按钮 ≥40–44（`--mgmt-btn-h-elder`）、表格行高 ≥56（`--mgmt-table-row-h-elder`）。
- 正文提升至 16–18、页标题 22–24（设计说明 §5.3.1.2 原值，基于基准标题 16px 基线；本端标准字号为适配值，适老各档位不得低于标准档）；正文对比加深；状态标签保持「浅底 + 深字 + 描边」。
- 不改变业务流程与字段结构；偏好按账号记忆。

## 7. 状态与等级映射（枚举，复制即用）

  1: 'var(--color-alarm-1)',

## 8. 代码生成自检清单

- [ ] 根节点挂了 `data-theme="mgmt"`，未重定义 token，无硬编码色 / 字号 / 尺寸。
- [ ] 同屏字号 ≤ 4 档；状态全部用 `.tag-*` 或 §7 映射，无自造色。
- [ ] 无大屏风格泄漏（玻璃 / 发光 / 科技青 / 深色底 / 登录渐变进表格页）。
- [ ] 骨架为「深蓝顶栏 56 + 侧栏 220 + 主区白卡」，页边距 24–32。
- [ ] 筛选控件等高 40 成组；表格浅主色表头 + 白底行 + 行高 48 + 隔行变色（斑马纹）。
- [ ] 向导有步骤条、详情有垂直时间轴，页签用下划线，三者不混用。
- [ ] 弹窗白底圆角 + 深色遮罩 + 取消 / 确定底栏；反馈分级正确，一屏主行动唯一。

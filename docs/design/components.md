# 组件级 UI 规范（三端统一）

> 本文档补强三端 UI 规范的**组件级空白**。既有 `docs/UI规范-{大屏端,后台管理端,移动端}.md` 仅描述颜色 / 间距 / 字号等 token 级约束；本文件定义**组件行为级**规范：Button / Form / Table / Empty State / 弹窗 / 表单校验态 / 加载态 / 错误态，并附「大屏 vs 后台 vs 移动」三端差异对比表。
> 所有视觉值一律 `var(--token)` 引用，禁止硬编码；端间互斥以 AGENTS §6.3 红线为权威源（见各端 UI 规范「§边界与互斥」）。

## 1. Button 按钮

| 端   | 主按钮                                                            | 次按钮          | 危险按钮                 | 触控目标 |
| ---- | ----------------------------------------------------------------- | --------------- | ------------------------ | -------- |
| 大屏 | 竖向蓝渐变 `--gradient-tech-blue` + 白字，圆角 `--btn-radius:2px` | 深蓝实底 + 描边 | 渐变红 `--gradient-risk` | ≥32px    |
| 后台 | 实色 `--primary-mgmt` 白字，圆角 `--mgmt-radius-sm/md`            | 白底描边        | 危险红链接 / 实色        | ≥32px    |
| 移动 | 实心主色**胶囊** `--mb-radius-btn:999px` + 白字，高 ≥48px         | 白底深描边      | 实色危险                 | 48–56px  |

- 通用：hover 有明确状态变化；disabled `opacity:.5 + cursor:not-allowed`；一屏主行动唯一（后台 / 移动）。
- 反模式：大屏禁止后台实色平涂按钮混入；后台 / 移动禁止大屏玻璃发光按钮。

## 2. Form 表单

- 大屏：暗底表单，控件描边亮蓝，聚焦发光。
- 后台：白底表单，控件等高 40px（`--mgmt-ctrl-h`）成组；左标签右值，分区标题 + 左色条。
- 移动：白卡分组，行「左标签（标题色）右值 / 占位」；必填标记明确，**占位符不得替代必填说明**；多选进底部选择器。
- 通用：提交校验必填项与字段格式；多步用步骤条（当前 / 已完成 / 未到三态）。
- 反模式：用占位符替代必填说明；多步表单缺失步骤反馈；后台/移动误用大屏暗底控件。

## 3. Table 表格

- 大屏：暗底高密度表，状态用语义色而非浅底标签。
- 后台：白底行 + 浅主色表头 + 行高 48 + **隔行变色（斑马纹）**；状态列 `.tag-*` 浅底同色标签。
- 移动：卡片化列表（非传统表格），左文右箭头；数据列表开启隔行变色。
- 通用：分页当前页实心主色；操作列主操作浅底 / 链接、弱操作文字链接。
- 反模式：大屏用浅底标签表达状态（应用语义色）；后台关闭隔行变色致行混淆；移动强行套用高密度表格。

## 4. Empty State 空状态

- 三端统一：插画 / 图标占位 + 说明文案 + 引导操作按钮（如「新建」「刷新」）。
- 大屏深蓝底插画提亮；后台白卡内浅灰插画；移动居中轻柔插画。
- 反模式：空状态不得裸露「无数据」纯文字而无引导入口。

## 5. 弹窗（Dialog / Drawer / Sheet）

| 端   | 形态                                       | 遮罩                 | z-index          |
| ---- | ------------------------------------------ | -------------------- | ---------------- |
| 大屏 | 深蓝渐变底 Drawer/Dialog                   | `rgb(0 10 24 / 72%)` | `--z-overlay:30` |
| 后台 | 白底圆角 Dialog（`--mgmt-radius-lg:10px`） | `rgba(0,0,0,.45)`    | `--z-overlay:30` |
| 移动 | 居中确认弹窗 + **底部半屏 Sheet**          | 深色半透             | `--z-overlay:30` |

- 禁止：大屏白底办公弹窗；后台玻璃发光抽屉；移动玻璃质感弹层（见各端「§边界与互斥」）。

## 6. 表单校验态

- 错误字段：红框（`--color-danger`）+ 文案提示（引用 `--color-danger`）；后台 / 移动用 `.tag-danger` 同色深字标签。
- 大屏：错误态用红色语义色高亮，不依赖浅底标签。
- 移动：错误说明不得用高亮浅字，强光下须可读。
- 反模式：仅用颜色表达错误（须配文案）。

## 7. 加载态

- 大屏：面板内柔和过渡动效 / 骨架屏，科技蓝脉冲。
- 后台：表格 / 卡片骨架屏或 spinner，浅色场用中性灰。
- 移动：列表骨架屏 + 下拉刷新 loading，克制动效。
- 通用：加载中禁用主操作，避免重复提交。
- 反模式：加载中仍允许重复提交；用整页白屏代替骨架屏；大屏过度动效干扰态势研判。

## 8. 错误态

- 轻提示（Toast）→ 内联错误 → 重试：反馈按打断程度分级。
- 大屏：高亮动效 + 弹窗主动触达；后台：`--danger-mgmt` 内联 + 确认弹窗；移动：轻提示 + 结果页 + 重试按钮。
- 反模式：错误态吞没信息（须给出可操作下一步）。

## 9. 三端差异对比表（速查）

| 维度        | 大屏                      | 后台               | 移动                     |
| ----------- | ------------------------- | ------------------ | ------------------------ |
| 容器材质    | 深蓝半透玻璃 `--glass-bg` | 白卡 `--card-mgmt` | 白卡 `--card-mobile`     |
| 圆角        | 2/4/10px                  | 4/6/10px           | 16px 卡 / 999px 胶囊     |
| 阴影 / 光效 | 内发光 `--glow-inner`     | 扁平描边           | 柔阴影弱依赖             |
| 字号梯度    | 多档（显示 38→辅助 12）   | 同屏 ≤4 档         | 同屏 ≤4 档               |
| 触控目标    | ≥32px                     | ≥32px              | 严格 48–56px             |
| 底色        | 深藏蓝 `--color-bg`       | 浅灰 `--bg-mgmt`   | 浅灰 `--bg-mobile`       |
| 状态语言    | 语义色直接                | `.tag-*` 浅底标签  | `.tag-*` 浅底 + 同色边框 |

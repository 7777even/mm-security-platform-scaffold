## 3. 测试中发现并修复的问题

1. 顶部区域与右侧工具列重叠 → 模块右让 120px；
2. 抬高层级修复后又遮挡“工具栏” → 回退层级，改用内容避让；
3. L2 与底部按钮重叠 → 模块最大高度 `calc(100vh - 210px)`，1366 短屏亦不重叠；
4. 旧“阶段一~五”文案残留（底部进度条、右侧动态卡）→ 统一替换为 9 节点新流程；
5. 阶段切换未联动预案 → 恢复响应模式 watch（公司级/政府级切环境预案）。

# 功能交付测试规范（工程流程固化）

> 规则：**每个功能完成后，必须依次通过“流程视角 → 功能完整性视角 → 用户体验视角”三层测试，全部通过并留档截图后，方可交付产品经理。**

## 1. 流程视角测试（用户能不能走通）

目标：验证用户从入口到结果的主流程闭环。

- [ ] 入口清晰可发现（按钮/导航位置符合预期）；
- [ ] 主流程可完整走通：进入 → 操作 → 结果可见；
- [ ] 流程步骤可推进/回退，状态正确（进行中/完成/未开始）；
- [ ] 跨模块联动正确（时间轴 ↔ 矩阵 ↔ 地图 ↔ 面板）；
- [ ] 返回/关闭/重进后状态不丢失或按预期重置；
- [ ] 异常分支有提示（空数据、无权限、网络失败等不白屏）。

## 2. 功能完整性视角测试（该有的都有）

目标：验证功能清单覆盖与边界。

- [ ] 对照需求/方案清单逐项核对，无缺失项；
- [ ] 列表/表格空态、加载态、完成态齐全；
- [ ] 按钮禁用态、hover、active、loading 反馈齐全；
- [ ] 数据字段完整（标题、状态、时间、责任人、数量等不缺失）；
- [ ] 长文案截断、溢出处理正确；
- [ ] 新增/删除/编辑等操作后界面即时刷新；
- [ ] `npm run build`（vue-tsc 类型检查）通过；
- [ ] 旧功能回归（本次改动影响的相邻模块无破坏）。

## 3. 用户体验视角测试（看着舒服、用着顺手）

目标：验证视觉与交互质量。

- [ ] 视觉与 UI 设计基准一致（颜色、边框、字体、间距、切图资源）；
- [ ] 交互反馈及时（hover 高亮、点击动效、状态颜色语义正确）；
- [ ] 弹窗/抽屉层级与动画符合规范（时长 0.2~0.42s，z-index 正确）；
- [ ] 地图可见性符合场景（不被面板长期遮挡，支持展开/收起）；
- [ ] 1366 / 1920 / 2560 三档尺寸检查通过；
- [ ] 关键路径截图留档（docs/演示截图/），供产品经理确认；
- [ ] 页面无遮挡、无错位、无空白闪烁。

## 4. 交付流程

1. 开发完成 → 本规范三层测试 → 修复问题；
2. 更新 `二级页面补充进度表.md`（状态 + 测试记录）；
3. 截图留档并交付产品经理确认；
4. 产品经理确认前，不进入下一批功能。
